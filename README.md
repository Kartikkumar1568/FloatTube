# FloatTube

**FloatTube** is a lightweight Chrome extension that instantly transforms any supported YouTube video into a floating Picture-in-Picture (PiP) window, allowing you to watch videos while working across applications.

Designed for developers, students, designers, and professionals, FloatTube provides a distraction-free multitasking experience without requiring any external services or user accounts.

## ✨ Features

* 🎥 One-click Picture-in-Picture mode
* 🖥️ Floating video window for seamless multitasking
* ⚡ Fast and lightweight performance
* 🎯 Clean and intuitive user interface
* ⌨️ Keyboard shortcut support
* 🔒 Privacy-first design
* 📦 No account or sign-in required
* 🌐 No internet services or third-party APIs
* 🚫 No advertisements
* 💻 Works completely offline after installation

## 🚀 Use Cases

FloatTube is ideal for:

* Watching programming tutorials while coding
* Following online courses during note-taking
* Keeping meetings or livestreams visible while working
* Learning from educational videos without switching tabs
* Multitasking across multiple applications

## 🔐 Privacy

FloatTube is built with privacy in mind.

* No user data is collected.
* No browsing history is stored.
* No analytics or tracking.
* No cloud services or external APIs.
* All functionality runs locally within your browser.

## ⚙️ Requirements

* Chromium-based browser
* YouTube video page
* Browser support for Picture-in-Picture (PiP)
